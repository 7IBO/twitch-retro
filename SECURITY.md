# Security

If you find a way to read someone else's data, to make the site send data it
should not, or to abuse its API, write to hello@7ibo.dev instead of opening a
public issue. You will get an answer within a few days.

The site has no accounts and no database: the export is read in the browser,
and the API (`api/`, `server/`) only relays public data from Twitch, 7TV,
BetterTTV and FrankerFaceZ.
